# 美术资源配置工具

把美术资源库里的资源（图标、图片、特效等）批量写入配置表（xlsx）的资源字段，并校验已填资源值的存在性。

## 技术栈

- Python 3（tkinter 界面）
- openpyxl：读取 xlsx 结构与数据
- pypinyin + pypinyin-dict（《现代汉语词典》读音库 kxhc1983）：中文名称转拼音，含多音字全读音组合
- 写入不经过 openpyxl，直接修改 xlsx（zip）内目标工作表的 XML

依赖安装：

```bash
pip install openpyxl pypinyin pypinyin-dict
```

## 启动

```bash
python art_tool.py          # 或双击 美术资源配置工具.vbs（Windows 无黑窗启动）
```

没有 Python 环境时，用 Releases 里的 exe，双击即用。

## 使用方法

顶部先设置「资源库根目录」（递归收录全部文件类型，会记住），并用「资源类型」列表勾选参与匹配的文件扩展名（默认全选）。

### 批量匹配（页签1）

1. 「选择配置表…」选一个 xlsx，再选子表
2. 选「匹配字段（名称）」和「要填的字段（资源）」
3. 选写入格式：
   - **文件名**：只写文件名词干，如 `icon_item_apple`
   - **相对路径+文件名**：写相对路径，如 `plants/grow_effect`。此时可选「路径起始点」（资源库根目录或其某个父目录；选父目录时路径包含资源库自身目录名，如资源库 `D:\art\图标库`、起始点 `D:\art` → 写入 `图标库/plants/x`）
4. 可选：填「限定前缀/后缀」（逗号分隔多个），只有文件名符合限定的资源才参与匹配，用于锁定资源范围（如限定 `V1_icon_item_` 只匹配物品图标）
5. 「预览」查看结果；需要人工处理时点：
   - 「解决冲突」：列出冲突行（有多个候选资源），选资源 → 选行 → 指定
   - 「手动指定」：列出未匹配行，搜索整个资源库后指定
   - 「解决重复资源」：同一资源被多个不同名称命中时，选定只写入哪个名称的行
   - 「全部改动…」：完整改动列表，可按行排除/恢复
   所有人工指定按 文件+子表+字段+行号 记忆（本次运行内有效），弹窗关闭后自动刷新预览
6. 「开始写入」（需确认，写入前自动备份）

### 存在性校验（页签2）

选配置表 → 子表 → 资源字段（可多选）→ 校验方式（按文件名 / 按相对路径，可选路径起始点）→「开始校验」。只读不写表，输出缺失清单、冲突清单、空值与公式统计。

## 匹配算法

1. **名称侧**：中文名称生成候选集——拼音全拼（`苹果派` → `pingguopai`）、首字母（`pgp`）、原名小写；多音字生成全读音组合（`参` → can/cen/shen）
2. **文件名侧**：去掉扩展名后按 `_`、`-`、空白、数字边界拆成词元（`V1_demo_d_item_pgp1` → `[demo, d, item, pgp]`，末位词元剥掉尾部数字）
3. **命中层级**（只取最高层级的最优结果）：
   - 第 1 级：规范化后整名完全相等（`yunwumaojian`）
   - 第 2 级：候选等于文件名中连续的一段词元（`apple` ∈ `icon_item_apple`）
   - 第 3 级：候选与某词元互为子串——疑似匹配，**不自动写入**，进冲突清单人工选定（防止「苹果派精华」误配「苹果派」的资源）
4. **判定**：第 1、2 级唯一命中 → 自动写入；多个同分候选 → 冲突；无候选 → 未匹配。冲突候选的写入值全部相同时（同名文件分处不同目录）不算冲突

## 写入规则

- 只写数据区（第 2 行起），表头永不修改
- 空名称的行跳过；目标单元格是公式的跳过
- 值已一致的行跳过；已填值与新值不同默认覆盖（日志单列旧值 → 新值）
- 同一资源被多个不同名称命中时，未人工决定一律不写入
- 新值已被其他名称的行占用（资源重复分配）时默认排除，可在「全部改动」里恢复
- 冲突、未匹配的行不写入，人工指定后写入

## 写入实现

xlsx 是 zip 包。写入时只替换 zip 内目标工作表的 XML：修改目标单元格（复用或追加共享字符串；原文件没有共享字符串表时用内联字符串），zip 内其余文件（其他工作表、公式缓存值、样式、主题）字节级保留。与整表重写（openpyxl 保存）相比，不会丢失公式缓存值，不影响下游转表。

其他防护：

- 预览与写入分离，确认后才执行
- 写入前自动备份原文件（默认「资源写入备份」目录，可自定义）
- 先写临时文件再原子替换，中途失败原文件不损坏

## 打包为 exe

```bash
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --clean --name 美术资源配置工具 \
  --collect-data pypinyin --collect-data pypinyin_dict \
  --exclude-module PIL --exclude-module lxml --exclude-module ssl \
  --exclude-module unittest --exclude-module doctest --exclude-module pydoc \
  --exclude-module turtle --exclude-module lib2to3 --exclude-module xmlrpc \
  --exclude-module multiprocessing --exclude-module concurrent art_tool.py
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `art_tool.py` | 入口（启动界面） |
| `core.py` | 纯逻辑：资源库扫描/匹配算法/xlsx 读写/批量匹配/占用检测/存在性校验 |
| `gui.py` | tkinter 界面：主窗口 + 解决冲突/解决重复资源/全部改动 弹窗 |
| `美术资源配置工具.vbs` | Windows 无控制台启动器 |
| `工具配置.json` | 运行时生成：目录设置、限定前后缀 |
| `资源扫描缓存.json` | 运行时生成：资源库扫描缓存 |
| `资源写入备份/` | 运行时生成：写入前自动备份 |
