# 美术资源配置工具

扫描美术资源库，按名称拼音（全拼/首字母/包含）把资源标识批量写入配置表（xlsx），并校验已填资源值的存在性。基于 Python + openpyxl + pypinyin + tkinter。

## 启动

```bash
pip install openpyxl pypinyin
python art_tool.py          # 或双击 美术资源配置工具.vbs（Windows 无黑窗启动）
```

要求：python.org 官方版 Python 3（自带 tkinter）。

## 核心概念

一个资源库根目录（递归收录全部文件类型），写入格式每次操作自选：

| 写入格式 | 写入内容 |
|---|---|
| 文件名 | 词干（不含扩展名），如 `icon_hb_shuidi` |
| 相对路径+文件名 | 相对「路径起始点」的路径（`/` 分隔，不含扩展名），如 `chashu/shengzhang_texiao` |

**路径起始点**：下拉选择资源库根目录的某个父目录作为相对路径的起算点（默认「资源库根目录」）。例如资源库是 `D:\art\图标库`，起始点选 `D:\art`，文件 `D:\art\图标库\chashu\x.png` 写入 `图标库/chashu/x`（路径包含资源库自身目录名）。「保留扩展名」复选框默认不勾（与存量数据一致）。

## 匹配规则

名称（如「番茄炒蛋」）生成候选：拼音全拼 `fanqiechaodan`、首字母 `fqcd`、原名小写——**多音字全读音组合**（如「参」同时生成 can/cen/shen，「林下参」能命中 `lxs`）。文件名按 `_`/`-`/数字边界拆词元后比对，优先级：

1. 整名规范化后完全相等（`yunwumaojian`）
2. 候选等于文件名中连续的一段词元（`shuidi` ∈ `icon_hb_shuidi`）
3. 候选是某词元的子串（剥尾部数字后，`fqcd` ⊂ `fqcd1`）——**疑似匹配，不自动写**，进冲突清单人工选定（防止「红颜草莓精华」撞上「红颜草莓」的资源）

只自动处理前两级无争议命中；**多个同分候选判冲突，未命中列未匹配，都不自动写**。

**同名称多行提示**：同一名称的多行写入同一资源时（道具ID可能不同），日志会列出这些行供人工核对，但不自动拦截。

**限定前后缀**：批量匹配页签可填写资源文件名的限定前缀/后缀（逗号分隔多个，如 `V1_icon_zw_`），**只有符合限定的资源才参与匹配**——用于锁定资源范围（如只匹配图鉴图标、排除生长状态图）。记住上次填写内容。

**资源侧核查**：预览/写入的日志里会额外列出两类资源，便于检查命名是否正确——不符合限定前后缀的资源（未参与匹配，可能是命名写错了前缀）、范围内未被任何行命中的资源（可能多余或名称对不上）。

**已有配置值的处理**：单元格已填值且与新值不同时**默认覆盖**（占位用的临时资源本来就该被替换），预览和写入日志会单列「已有配置值将被覆盖」清单，逐行显示 `旧值 -> 新值`，方便核对哪些临时资源被替换了；值已一致的行不动，公式单元格永不覆盖。

**全部改动窗口**：「全部改动…」列出所有待写入改动（不受预览 200 条上限限制），双击或选中按空格切换 写入/排除，也支持多选后批量「排除选中/恢复选中」。排除按 文件+子表+字段 记住，预览和写入都生效——命名混乱的表先在这里把张冠李戴的行挑出去。

**重复资源拦截**：同一资源被多个**不同名称**命中时（首字母碰撞的典型信号，如「经验」和「鲫鱼」都命中 `jy1`），未人工决定前一律不写入，日志会列出。「解决重复资源」弹窗里逐个选定：只写入某个名称的行，或都不写。同一名称多行共享资源（如多星级作物）不算重复，正常写入。

## 功能与操作

**资源类型筛选**：顶部「资源类型」多选列表列出资源库里出现的所有扩展名（如 `.png`、`.jpg`、`.json`），默认全选（即全部参与）；勾选部分类型后，匹配、校验、手动指定都只在勾选的类型范围内进行。

### 批量匹配（页签1）

1. 顶部设置 资源库根目录（会记住）
2. 「选择配置表…」直接选一个 xlsx → 选子表 → 选匹配字段（名称）和要填的字段（资源）→ 写入格式 →（可选）路径起始点、忽略前后缀
3. 「预览」查看 自动匹配 / 冲突 / 未匹配 三组明细
4. 「解决冲突 / 手动指定」：左侧搜索选中资源（选中行后可只看该行候选），右侧搜索并勾选要写入的行（显示行号、名称、旧值，可多选），点「← 指定给选中的行」——指定粒度是**行**，同名称不同道具ID的行可分开指定
5. 「开始写入」（确认后执行，自动备份）

### 存在性校验（页签2）

「选择配置表…」→ 选子表 → 资源字段（可多选）→ 校验方式（按文件名 / 按相对路径，可选路径起始点）→「开始校验」。只读不写表，输出 缺失清单 / 冲突清单 / 空值与公式统计。

### 防护机制

- 所有批量操作先「预览」看改动清单，确认后才写入
- 写入前自动备份（默认「资源写入备份」文件夹，可自定义目录）
- 临时文件原子替换保存，中途失败不损坏原文件
- **表头永不被修改**，所有操作只写数据区（第 2 行起）
- 公式单元格不读不写（目标是公式的跳过并警告）

## 打包为 exe

```bash
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --clean --name 美术资源配置工具 \
  --exclude-module PIL --exclude-module lxml --exclude-module ssl \
  --exclude-module unittest --exclude-module doctest --exclude-module pydoc \
  --exclude-module turtle --exclude-module lib2to3 --exclude-module xmlrpc \
  --exclude-module multiprocessing --exclude-module concurrent art_tool.py
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `art_tool.py` | 工具主程序（纯逻辑函数 + tkinter 界面） |
| `美术资源配置工具.vbs` | Windows 无控制台启动器 |
| `工具配置.json` | 运行时生成：目录设置、忽略前后缀 |
| `资源扫描缓存.json` | 运行时生成：资源库扫描缓存 |
| `资源写入备份/` | 运行时生成：写入前自动备份 |
